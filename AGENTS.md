# Rules & Guidelines

- **Testing UI**: Jangan melakukan verifikasi/pengetesan UI melalui browser. Gunakan Kotlin UI test / unit test secara langsung.
- **Desain & Target Device (Tablet-First)**: Aplikasi ini dirancang utamanya untuk perangkat **Tablet (Tablet-First)** dengan orientasi layar **Landscape**. Meskipun demikian, aplikasi harus tetap adaptif dan mendukung (*support*) tampilan untuk **Mobile** maupun **Desktop**, namun prioritas hierarki tata letak dan desain awal selalu ditujukan untuk kenyamanan penggunaan tablet kasir landscape.
