# Rules & Guidelines

- **Testing UI**: Jangan melakukan verifikasi/pengetesan UI melalui browser. Gunakan Kotlin UI test / unit test secara langsung.
- **Desain & Target Device (Tablet-First)**: Aplikasi ini dirancang utamanya untuk perangkat **Tablet (Tablet-First)** dengan orientasi layar **Landscape**. Meskipun demikian, aplikasi harus tetap adaptif dan mendukung (*support*) tampilan untuk **Mobile** maupun **Desktop**, namun prioritas hierarki tata letak dan desain awal selalu ditujukan untuk kenyamanan penggunaan tablet kasir landscape.
- **Arsitektur UI (Common-First)**: Seluruh tampilan antarmuka (UI), screens, dialog, komponen, tema/styling, dan alur navigasi wajib diatur dan berada di dalam `commonMain` (Compose Multiplatform). Modul platform-spesifik (`androidMain`, `wasmJsMain`, `desktopMain`) hanya berfungsi sebagai *entry point* (seperti `MainActivity` yang langsung memanggil `CommonApp()`) atau jembatan integrasi native spesifik (perangkat keras seperti printer thermal, kamera, dsb.) melalui mekanisme `expect`/`actual` atau interface, dan TIDAK BOLEH membuat atau menduplikasi UI sendiri di luar `commonMain`.
